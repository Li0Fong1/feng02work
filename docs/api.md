# API 参考

这一页只用来练习怎么写接口说明，下面这些接口没有真实服务，别照着去请求。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：按 id 返回一篇文档的标题和正文。

```json
{
  "id": 1,
  "title": "使用指南",
  "body": "改 docs 里的 Markdown，然后推送。"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | 整数 | 条目编号 |
| title | 字符串 | 页面标题 |
| body | 字符串 | 正文摘要 |

## 说明

字段是随手定的，够用来演示代码块和表格就行。真要写能用的接口文档，还得补状态码、错误格式和鉴权方式，这次没做。回到[首页](index.md)，或者看[使用指南](guide.md)。
